# ExamBuddy Mini App — test build

Статическая сборка Telegram Mini App для подготовки к IELTS.
Репозиторий нужен только для деплоя на GitHub Pages — задача EX-3, тестовый домен.

Исходный код: приватный репозиторий aidynabirov/exambuddy, ветка Baga_NewApp, папка miniapp.
Здесь лежит только результат сборки: вёрстка и демо-данные. Бэкенда, ключей и токенов нет.
Данные моковые, прогресс хранится в localStorage браузера.

Адрес используется как Web App URL у тестового бота в BotFather.
